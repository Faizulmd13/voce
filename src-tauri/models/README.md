# Voce Local AI Models

This directory contains the quantized weights for local on-device AI processing:

1. **Whisper STT Model**: `ggml-base.en.bin` (142 MB)
2. **Translation Model**: `nllb-200-distilled-600M` / `CTranslate2` models

All AI computation executes 100% locally on the user's device with zero telemetry or cloud API calls.
